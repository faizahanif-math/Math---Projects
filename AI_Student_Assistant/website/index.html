🤖 AI Student Assistant

Smart Study Planner & Student Performance Assistant

📚 About the Project

AI Student Assistant is a Python-based educational project designed to help students organize their studies, track academic progress, calculate CGPA and receive personalized study recommendations.

✨ Features

📚 Smart Study Planner

Create a study plan based on your subjects.

📊 Progress Tracker

Track completed topics and calculate progress.

🧮 CGPA Calculator

Calculate CGPA using grade points and credit hours.

🎯 Study Recommendation

Get recommendations based on available study time.

📈 Performance Analysis

Analyze academic performance using CGPA and progress.

🎓 Student Dashboard

View student information and available tools.

💻 Technologies Used

Python HTML CSS JavaScript VS Code GitHub

🚀 Project Highlights

This project combines multiple student-focused tools into one application, including study planning, progress tracking, CGPA calculation, recommendations and performance analysis.
